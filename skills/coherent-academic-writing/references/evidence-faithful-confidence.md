# 主张、证据与措辞

先记录主张的对象、条件、比较对象、指标、效应方向/大小、不确定性以及来源定位。
逐条区分可观察事实、作者解释、尚待验证假设；未见原始数据只表示未独立复算，不否定已提供事实。

| 决策 | 使用条件 | 例子 |
| --- | --- | --- |
| REMOVE | 无事实、范围或推断功能的防御性赘语；删除不改变可检验含义 | “遗憾的是，A 的准确率为 71%，低于 B 的 76%。”只删“遗憾的是”，保留两数和比较。 |
| REFRAME | 事实充分，评价性措辞夸大失败或贡献；可中性改写 | “方法彻底失败”→“在该测试集上未超过基线”，前提是证据确实如此。 |
| RETAIN | 必要限制、负面结果、范围限定、统计谨慎或披露要求 | “仅在单中心样本中验证”“未检出显著差异”保留。 |
| NARROW_CLAIM | 主张强于证据，应缩小对象、条件或推断强度 | “所有场景均领先”与表中反例冲突时，限定到已支持场景并同时报告反例。 |
| ESCALATE_TO_AUTHOR | 事实冲突、关键来源缺失、机制或取舍无支持 | 请求核实数据或提供依据；不给看似合理但未经证实的机制。 |

同一句可有不同子片段决策，分别定位；例如删道歉同时保留不利比较。
不要把负面证据转化成不相关指标上的胜利，也不要把“差异不显著”写成“同样有效”。
说明取舍需同时有两端数据及相同评估条件；解释机制需独立证据，否则明确是假设或保留未知。
优点可以明确表达，但“首次”“最佳”“显著”“因而导致”等需要对应证据；没有就收缩或询问。
若要求隐藏必要负面结果，说明该修改会失真，提供保留事实并缩小主张的替代方案。
