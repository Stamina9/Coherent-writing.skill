# 六项章节边界审查

先采用 section-policies 中的 profile。下表是需要阅读上下文的线索，不是自动裁决规则。
每个建议须说明该内容承担的论证功能、当前位置造成的具体障碍，以及移动后的承接关系。

| 维度 | 定位线索 | 判断及例外 |
| --- | --- | --- |
| 摘要聚焦 | 大段背景、对他人工作的介绍、引用或技术展开 | 是否妨碍交代问题、方法、主要结果和范围？结构式摘要、综述或 venue 允许的引用可保留。必要限制不能为“更自信”而删除。 |
| 引言边界 | 实现参数、公式、长相关工作 | 是否为理解问题或贡献所必需？理论论文可在引言给形式化定义；不以公式出现或相关工作占比判违规。 |
| 方法可理解与可复现 | 长文献评价、背景、结果讨论 | 动机、对照设计、领域原理和复现参数可属于方法。无需以“我们”开头，也无一句话/三句阈值；只有遮蔽方法且可独立放置的综述才建议移动。 |
| 结果叙述 | 重复方法、解释或意义延伸 | 分开结果/讨论时可建议移位；合并 Results and Discussion 时允许解释。保留负面结果、不确定性和必要比较，保留理解结果所需的简短方法提醒。 |
| 讨论推进 | 反复列数值、首次出现数据、流程复述 | 引用关键数值来解释效应大小或矛盾是合理的。首次结果应核实来源与 venue 结构，不能仅凭出现数字判违规；不删除反证。 |
| 结构一致性 | 编号跳跃、同名标题、占位符、图表位置 | 结合附录、分篇论文、自动编号和跨章相同小节名判断。只报告真实残留占位符，勿将引文中的 TODO 当作者待办。浮动图在视觉上的位置不能从 XML 顺序断定。 |

重复检查须并列给出两个来源，区分必要提示、合法复述与无新增信息的整段重复。
不能以未经标定的相似度、每百字数字数量或任意字数阈值决定严重度。
严重度取决于论证受损、可复现信息丢失或读者误解的实际影响；仅有线索时标“待核实”。
移动内容时保留原定位→目标章节的映射；不得因目标章不存在而自行套用 IMRaD。
