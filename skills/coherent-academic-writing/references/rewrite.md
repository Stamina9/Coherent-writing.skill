# 批准后最小改写

1. 对齐审批：来源 hash/版本、问题 ID、批准的动作和目标输出。已有明确且仍适用于当前版本的
   批准可直接使用；源文改变时重新核对受影响提案，不重复询问未变化项。
2. 默认只改必要词句，保留作者术语、句序、段落、引文和所有无问题内容。
   移段时保持证据与主张可追溯；删重复内容前核实其唯一信息已在明确目标保留。
   重组全文、增实验、改变统计解释都不在最小修改范围内。
3. 抽取器不承担 DOCX 写回。使用环境中可用且能保留所需格式的编辑方法。
   无法可靠保留复杂域、交叉引用或修订时，交付精确替换提案并标“未应用”，不要冒称已修好 DOCX。
4. 默认另存新副本；只有明确授权覆盖指定原稿才可备份后写回。审查阶段不产生原稿写操作。

## Evidence-integrity audit

对照完整原文和改后文本，逐条记录 pass / fail / blocked 及定位，不能只比较总字数或数字集合：

- 数值、单位、分母、样本/人群、时间范围、数据划分与比较对象的关联是否一致？
- 否定词、结果方向、统计不确定性、限制和必要反例是否保留且仍可见？
- 引用是否仍对应原主张，移动后图表/公式/交叉引用是否仍正确？
- 因果、机制、显著性和泛化强度是否被无依据抬高？每个新增事实是否有来源？
- 修改是否仅限批准范围，无问题文字是否原样保留？

任何 fail：撤销相关变更，提供修正建议；任何影响该项结论的 blocked：暂停交付该项为已完成。
重新抽取修订 DOCX 并核对锚点（索引可能变化，按内容映射），必要时视觉检查表格/图题/公式，
明确未做视觉或统计核验。只有已核验范围才可报告通过。
