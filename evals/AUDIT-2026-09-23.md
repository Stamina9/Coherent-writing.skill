## Reproduced defects and fixes

Four new regression tests failed against the previous extractor before implementation changes:

| Input/condition | Observed before | Fix and regression invariant |
| --- | --- | --- |
| Valid ZIP directory with invalid DEFLATE block in word/document.xml | Uncaught zlib.error, traceback, exit 1 | INVALID_DOCX, exit 4, empty stdout, no result file, source bytes unchanged. |
| Table row carrying w:trPr/w:del | No revision warning; coverage text-only | Inspect table XML as well as paragraphs; REVISIONS_NOT_RESOLVED and partial coverage, no revision accepted/deleted automatically. |
| w:sym character in an effect value | Symbol absent from text with no warning | INLINE_CONTENT_NOT_EXTRACTED and partial coverage; do not silently treat a missing sign as valid evidence. |
| Chinese output directory with PYTHONIOENCODING=ascii | Result written but path printing raised UnicodeEncodeError | UTF-8 stdout/stderr protocol, decodable existing result path; no CLI -X flag required. |

Supported compression is now explicitly stored/deflate. An additional test verifies that nonstandard ZIP
compression returns an actionable error. Table warnings can also occur at enclosing table and paragraph
anchors; consumers should use the location field and need not assume one warning per object.
